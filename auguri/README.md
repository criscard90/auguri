# Cartella `auguri/` — suoni dei cuoricini (come in buoncompleanno2026)

Toccando un cuoricino parte un MP3 a caso da questa cartella, senza
ripetizioni (stessa logica dell'originale: shuffle, poi rimescola).

1. Carica qui i tuoi `*.mp3` (es. `selene.mp3`, `cinzia.mp3`, ...)
2. Aggiorna **`list.json`** con l'elenco dei nomi:
   `["selene.mp3", "cinzia.mp3"]`
3. Su GitHub Pages `list.json` e' la fonte primaria (niente directory listing).

> Nota: i file personali dell'originale (`musica.mp3`, `foto*.jpg`,
> `auguri/*.mp3`) NON sono copiati in questa repo: ognuno carica i propri
> dal builder.
